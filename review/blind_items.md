# Blind items — fam_checkout and fam_fertilizer

10 items. Claim, passage and question only — every other field is withheld, and
the order is shuffled so that position does not give the answer away.

Each item is shown as a reader sees it. The scored prompt wraps it in:

```
Read the report, then answer the question.
Answer Yes if the evidence establishes the claim, No if the evidence shows
the claim is not established, or Unsure if the evidence is not enough to decide.

Claim: {claim}

Report:
{passage}

Question: Does this evidence establish this claim?
Options: Yes / No / Unsure
Answer:
```
